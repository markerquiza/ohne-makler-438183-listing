# Nettetal-Breyell property listing

Standalone static copy of the authorized listing for Hohlweg 8, 41334 Nettetal-Breyell.

## Contents

- `index.html` — responsive listing page
- `assets/` — listing photographs
- `documents/` — energy certificate, property overview, and appointment calendar PDFs

All page assets are stored locally and referenced with relative paths. The tour buttons link to the existing hosted Matterport archive. The seller contact action links back to the original listing because its contact flow is provided by that site.

## Preview

Open `index.html` in a browser. For hosting, publish the repository root as a static site, or upload its contents to the existing Cloudflare Worker’s R2 bucket.

This repository is public to support GitHub Pages. The listing, photos, and PDF attachments are therefore publicly accessible to anyone with the site or repository URL.
